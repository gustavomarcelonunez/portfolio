BotGBIF

Biodiversity Chatbot with LLM and GBIF API

Un prototipo web que combina búsqueda estructurada y conversación: recupera datasets desde GBIF mediante país, tipo y texto libre, y permite formular preguntas en lenguaje natural sobre la metadata recuperada o sobre las ocurrencias de un dataset específico.

El problema

Encontrar el dataset correcto no debería requerir dominar una API

GBIF ofrece una infraestructura global de datos de biodiversidad, pero explorarla programáticamente implica conocer endpoints, parámetros, estructuras JSON y las diferencias entre metadata de datasets y registros de ocurrencia.

BotGBIF propone una capa intermedia: conserva filtros explícitos para que la búsqueda sea controlable y suma un chatbot para interpretar los resultados sin obligar al usuario a recorrer manualmente estructuras técnicas.

Interacción en dos niveles

Primero se descubre el conjunto; después se profundiza en sus registros

El contexto del agente cambia según la selección del usuario. Esta transición evita mezclar la descripción general de múltiples recursos con el contenido de un dataset particular.

01 · Metadatacountry + type + full-text

El agente recibe la respuesta de búsqueda de GBIF y permite comparar títulos, fechas, DOI y demás metadata de los datasets recuperados.

02 · Ocurrenciasselected dataset → occurrence/search

Al seleccionar un dataset, el contexto se reemplaza por sus registros de ocurrencia y las preguntas se responden sobre ese contenido específico.

Flujo de uso

De una búsqueda guiada a una conversación focalizada

01FiltrarEl usuario combina país, categoría de dataset y una frase de búsqueda libre.
02RecuperarLa API de GBIF devuelve los datasets que cumplen los criterios y su metadata.
03ConversarGPT-4o-mini responde preguntas limitadas a los resultados recuperados.
04ProfundizarLa selección de un dataset habilita consultas sobre sus ocurrencias concretas.

La API determina qué datos se recuperan; el LLM funciona como capa interpretativa sobre el JSON resultante y no sustituye la consulta a GBIF.

Valor del prototipo

Una interfaz conversacional sin perder el control de la búsqueda

Los filtros mantienen visible la intención de búsqueda: dónde buscar, qué clase de recurso recuperar y qué término utilizar. El chatbot interviene después, cuando los datos ya están delimitados.

Esto permite preguntar qué datasets contienen información relevante, quién los publica o qué características aparecen en las ocurrencias del recurso seleccionado.

El agente responde únicamente a partir del contenido proporcionado por GBIF y limita su alcance a biodiversidad. Aun así, sus respuestas son orientativas y deben verificarse contra el dataset original.

Contexto de creación

Una propuesta para ampliar el uso de datos abiertos de biodiversidad

BotGBIF fue desarrollado y presentado en el marco del Ebbe Nielsen Challenge 2024, la competencia anual de GBIF orientada a soluciones innovadoras que aprovechan datos abiertos de biodiversidad.

La propuesta explora cómo los modelos de lenguaje pueden reducir la barrera entre una infraestructura global de datos y las personas que necesitan localizar, comprender y consultar sus recursos.

Equipo: Marcos Zárate, Darío Ceballos y Gustavo Marcelo Nuñez · CESIMAR–CONICET, Puerto Madryn.

Consulta representativa

Mirounga leonina

Una búsqueda puede combinar un país, el tipo “Occurrence” y el texto libre “Mirounga leonina” para localizar datasets relacionados con el elefante marino del sur.

A partir de allí, el usuario puede preguntar por la metadata del conjunto recuperado, comparar recursos y seleccionar uno para conversar específicamente sobre sus registros de ocurrencia.
